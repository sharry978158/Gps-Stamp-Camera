# GPS Stamp Camera 📸📍

An Android application that allows users to capture photos with embedded GPS location, date, time, and custom pin-point location details. Perfect for field work, site inspections, delivery verification, and travel journaling.

---

## 🚀 Features

* *Real-time GPS Stamping:* Automatically fetches and stamps current coordinates (Latitude/Longitude), address, date, and time onto captured photos.
* *Custom Edit Mode:* Easily edit or pin-point custom locations, dates, and times before or after capturing the image.
* *Map Integration:* Visual map pin-pointing support for accurate location tagging.
* *Clean & User-Friendly UI:* Simple layout optimized for quick capturing and editing.
* *Customizable Stamps:* Adjust how location data, timestamps, and notes appear on your photos.
